# Haskell Simple CLI Template

Create a repository with [Use this template](https://github.com/totto2727-org/template-haskell-simple/generate), then ask an AI coding agent to follow [AGENTS.md](./AGENTS.md).

This template uses Cabal and hpack for the project and Nix for the toolchain.
Local development and CI use the same `flake.lock`, without ghcup.

Give the agent your project name, purpose, and publication targets:

```text
Read AGENTS.md and initialize this repository according to its instructions.
Project: <owner/repository, Cabal package name, and command name>
Purpose: <what the project should do>
Publication: <Hackage, FlakeHub, or neither>
Customize the project metadata and documentation for this project.
Do not publish packages or enable publishing workflows before the required publication settings are configured.
```
